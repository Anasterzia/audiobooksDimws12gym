# Ηχητική Βιβλιοθήκη (στατική βιτρίνα + myfiles ΠΣΔ)

Στατική ιστοσελίδα (χωρίς server) που δείχνει τα βιβλία: εξώφυλλο, περιγραφή, συγγραφέα, παιδιά που διάβασαν και **πού να βρουν τα αρχεία ήχου στο myfiles.sch.gr**. Τα ίδια τα αρχεία ήχου μένουν στο myfiles, με πρόσβαση μόνο μέσω SSO του ΠΣΔ.

## Πώς δουλεύει
1. Ανεβάζετε τον ήχο του βιβλίου σε έναν φάκελο στο **myfiles** (στο «home» σας).
2. Μοιράζεστε τον φάκελο (κουμπί «Διαμοιρασμός Αρχείου») με μια **ομάδα χρηστών**, με συγκεκριμένα σχολεία ή με όλα. Δεν χρησιμοποιείτε «Δημοσιοποίηση», γιατί αυτή δίνει σύνδεσμο που ανοίγει χωρίς είσοδο.
3. Ο χρήστης συνδέεται στο myfiles με τον λογαριασμό sch.gr και βρίσκει τα αρχεία στο `public → όνομα-χρήστη-σας` (ή `shared`).
4. Στη βιτρίνα προσθέτετε το βιβλίο και γράφετε στο πεδίο «Πού βρίσκεται στο myfiles» τη διαδρομή.

## Προσθήκη βιβλίου
- Ανοίξτε `admin.html` (στο site σας ή τοπικά), προσθέστε το βιβλίο, πατήστε **Λήψη books.json** και ανεβάστε το στο GitHub πάνω στο παλιό.
- Εξώφυλλα: ανεβάστε την εικόνα (JPG/PNG, ιδανικά τετράγωνη) στον φάκελο `covers/` και γράψτε `covers/όνομα.jpg`.
- Αν προτιμάτε, επεξεργαστείτε κατευθείαν το `books.json` στο GitHub.

## Δημοσίευση στο GitHub Pages
1. Φτιάξτε αποθετήριο στο GitHub και ανεβάστε όλα τα αρχεία.
2. *Settings → Pages → Deploy from a branch → main / root*.
3. Η σελίδα ανοίγει στο `https://ΟΝΟΜΑ.github.io/ΑΠΟΘΕΤΗΡΙΟ/`.

## Προσοχή
- Η βιτρίνα είναι **δημόσια**: όποιος έχει τον σύνδεσμο βλέπει τίτλους, περιγραφές, εξώφυλλα και **ονόματα αναγνωστών**. Βάλτε μόνο μικρά ονόματα ή ψευδώνυμα και βεβαιωθείτε ότι έχετε συγκατάθεση των γονέων.
- Η ασφάλεια των αρχείων ήχου εξαρτάται αποκλειστικά από το πώς τα μοιράζεστε στο myfiles. Ελέγξτε σε ανώνυμο παράθυρο ότι τα αρχεία δεν ανοίγουν χωρίς είσοδο.
- Ο οδηγός χρήσης του myfiles που βασιστήκαμε είναι του 2017. Αν η υπηρεσία έχει αλλάξει, προσαρμόστε το κείμενο της σελίδας.
